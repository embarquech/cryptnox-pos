Detailed Description

Touchscreen UI implementation built on LVGL 8.x.

TFT_eSPI is used only as the low-level panel driver (the LVGL flush callback pushes rendered pixels to it); XPT2046_Touchscreen feeds the LVGL pointer input device. All LVGL calls happen on the single UI task — the public ui_show_* entry points (called from the main task) only stage a screen request + its data and raise a dirty flag, which the UI task drains.
