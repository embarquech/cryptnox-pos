Simple housing for Cheap Yellow Display (CYD) with USB-C by DE_Markus on Thingiverse: https://www.thingiverse.com/thing:6440252

Summary:
I needed a simple case for the Cheap Yellow Display (ESP32-2432S028R) CYD in landscape mode (but can also be used in portrait mode). Main goals:Small caseSupports CYD version with USB-C portOpening for light sensitive resistor (LDR) to allow automatic scren brightness adjustment. This requires a solid light barrier between the display and the LDR, otherwise the automatic adjustment is influenced by the backlight LEDs themselvesOpening in the back for the LEDBoot and reset buttons can be pushed via buttons in the back plane of the housingFront does not interfere witht he touch displayI have also made a stand which can be used in Portrait or Landscape mode (You will have to print two of these). Two versions are available, #2 (File Name "Markus_CYD_Stand_17-8.stl") is 0.1 mm narrower if you desire a tighter fit.Also included an alternative back that allows to use a 25 mm loudspeaker (8 Ohm, 0.5 W, available via Aliexpress). And last not least: stable housing that actually fits - I did some test prints to ensure that no rework is needed to fit the CYD into the housingThe design is based on Leo Ruiz' housing : https://www.thingiverse.com/thing:5990927, but completely redone in Fusion
