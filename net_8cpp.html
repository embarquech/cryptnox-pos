◆ net_time_sync()

bool net_time_sync ( uint32_t timeout_ms)

Block until the system clock has been set via SNTP.

Must be called after net_wifi_connect() and before any HTTPS request: without real time, TLS certificate validity-period checks are meaningless (F-06). SNTP keeps running in the background for periodic resyncs.

Parameters
[in]timeout_msMaximum time to wait for the first sync.
Returns
true once the first sync completes, false on init error or timeout.

int32_t event_id,
void * event_data )
static

WiFi/IP event handler driving the connect retry state machine.

Retries the association up to WIFI_MAX_RETRY times, then signals WIFI_FAIL_BIT; signals WIFI_CONNECTED_BIT once an IP is bound.

Parameters
[in]argUnused.
[in]event_baseEvent base (WIFI_EVENT or IP_EVENT).
[in]event_idEvent identifier within event_base.
[in]event_dataUnused.
