bool eth_addr_parse ( const char * hex,
uint8_t out[20] )

Parse a 20-byte Ethereum address from a hex string.

Accepts an optional 0x / 0X prefix, then requires exactly 40 hex characters and rejects any non-hex input instead of silently decoding garbage (F-07).

Parameters
[in]hexAddress string (with or without 0x prefix).
[out]out20-byte decoded address; zeroed then left partially written on failure — must not be used unless true is returned.
Returns
true on success, false on wrong length or non-hex character.
